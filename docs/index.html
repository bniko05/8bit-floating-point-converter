8-bit floating-point converter

Click the bits to build a number, or type a decimal value to see how it is stored. Uses the textbook format with a sign bit, a 3-bit excess-4 exponent and a 4-bit mantissa.

Sign
Exponent excess-4
Mantissa 0.mmmm

Accepts decimals, negative numbers and fractions such as 3/8.

How the format works

A value is stored as sign × 0.mmmm × 2exponent. The exponent bits are read in excess-4 notation, so 100 means 0, 111 means 3 and 000 means −4. When converting to binary, the number is normalized so the first mantissa bit is 1, and bits that do not fit are truncated.

Largest value0 111 1111 = 7.5
Smallest positive (normalized)0 000 1000 = 0.03125
Example with truncation2.625 → 0 110 1010 = 2.5
